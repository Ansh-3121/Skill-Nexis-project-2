🏦  Customer order  MySQL Data Analysis Project

📌 Project Overview

This project is based on a banking/order dataset. I used MySQL to clean the data and perform SQL analysis to find useful business insights related to customers, sales, products, orders, and regions.

🛠️ Tools Used

- MySQL
- MySQL Workbench
- SQL

📂 Dataset

The dataset contains information about:

- Order ID
- Order Date
- Customer Name
- Category
- Sub-Category
- Product Name
- Quantity
- Unit Price
- Total Price
- Region

🧹 Data Cleaning

I performed the following data cleaning tasks:

- Fixed an incorrect column name after importing the data
- Checked duplicate records
- Checked duplicate Order IDs
- Converted "order_date" into the correct date format
- Changed price columns to numeric data types
- Checked the table structure using "DESC"

📊 SQL Analysis

I used SQL queries to answer business questions such as:

- Total sales for the Clothing category
- Top 10 customers by purchase amount
- Top-selling category
- Top 5 selling sub-categories
- Average sales by category
- Customers with the highest and lowest purchase amounts
- Total number of orders
- Average order quantity
- Total sales
- Region-wise sales
- Year-wise orders
- Year-wise sales

The main objective of this project was to practice SQL and understand how SQL can be used to clean data and answer business questions.
